# indexed/

Generated by `python3 tools/build_index.py` from the JSON files in this repo (not from PDFs).

- `catalog.json` — one metadata row per JSON document (`id` = sha1 of relative path, 16 hex chars)
- `_jsonl/<area>.jsonl` — `{id,path,title,area,level,format,pages,words,text}`
- `_convert_stats.json` — counts

Per-document copies are **not** stored here; `path` points at the live JSON under `exams/`, `schemes-of-work/`, etc.
